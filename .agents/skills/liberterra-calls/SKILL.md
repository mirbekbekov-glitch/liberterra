# Liberterra — звонки агентов

## Почему не запись на телефоне
Приложения вроде «Мои звонки» пишут разговор на устройстве и стабильно работают только на старых Android: в новых версиях Google закрыл сторонним приложениям доступ к аудио звонка. Поэтому записывать нужно на стороне АТС/SIP-провайдера, тогда модель телефона не важна.

## Схема
1. Агент звонит из кабинета (кнопка «Позвонить» с обратным звонком) или из приложения Bitrix24/софтфона через SIP.
2. АТС пишет разговор и шлёт на наш сервер вебхук: направление, номера, время, длительность, ссылка на запись, идентификатор звонка.
3. Сервер проверяет подпись вебхука, находит агента по внутреннему номеру, клиента по нормализованному телефону (+996…). Неизвестный номер создаёт карточку «новый клиент».
4. Запись копируется в своё S3-хранилище или остаётся у провайдера со временным подписанным URL. В `activities` создаётся событие типа `call`.
5. Экран «Звонки»: фильтры по дате, клиенту, направлению; плеер; заметка; кнопка «создать задачу». Агент видит только свои записи.

## Требования
- Идемпотентность вебхука по id звонка (повторы не дублируют записи).
- Голосовое предупреждение о записи в начале звонка; политика хранения (срок, удаление по запросу) согласована с юристом по закону КР о персональной информации.
- Доступ к файлам только по короткоживущим подписанным ссылкам, без публичных URL.
- Опционально: расшифровка речи и краткое резюме (Claude API) → автоматические задачи. Это отдельный шаг после базовой записи.
- Перед выбором провайдера проверить: номера Кыргызстана, оплата, API и вебхуки, условия хранения записей. Не утверждать условия из памяти.
