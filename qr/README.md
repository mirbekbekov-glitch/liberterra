# QR-редиректы liberterra.kg

Worker `qr-redirect`. Маршруты в зоне: `liberterra.kg/qr/*` и `liberterra.kg/chayka*`.
Короткий адрес с баннера ведёт на видео; каждый скан пишется в Google Таблицу
«QR баннеры» (лист «Сканы»), ссылки берутся из листа «Ссылки» с кэшем 60 секунд.

## Запасной адрес

Раньше — `https://liberterra.kg/`. После того как домен освободили от старого
сайта, он стал приводить на ошибку 522, поэтому заменён на видео Чайки.

Менять его можно без правки кода: добавьте в лист «Ссылки» строку с именем
`по умолчанию` (или `default`) и нужным адресом в колонке B. Сработает в течение
минуты. Если такой строки нет, используется адрес из константы `FALLBACK`.

## Важное

В выложенном Worker ключ доступа к таблице записан прямо в коде. В этой копии он
заменён заглушкой. Когда дойдут руки — стоит перенести его в секретную переменную
Worker и заменить на новый.

## Выкладка

    curl -X PUT "https://api.cloudflare.com/client/v4/accounts/<account>/workers/scripts/qr-redirect" \
      -F "metadata=@meta.json;type=application/json" \
      -F "worker.js=@worker.js;filename=worker.js;type=application/javascript+module"
