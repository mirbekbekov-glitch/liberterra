# Разряды в ценах в сомах

## Что не так

На карточках каталога и главной цена печатается как «150000 сом». Разряды расставляются только для сумм в долларах: `price('$150000')` даёт «$150 000», а `price('150000 сом')` возвращает строку без изменений.

## Где это живёт на самом деле

Не в `/listing-format.js`. Этот файл отдаётся из карты, он уже исправлен в `assets/*/files/listing-format.js`, но на каталог и главную не подключается: тега со ссылкой на него там нет.

Форматтер приходит инлайновым блоком, который Worker вставляет при выдаче страницы, под условием «если window.LiberterraListingFormat ещё не определён». Имя маркера у блока разное, и искать надо по телу функции, а не по маркеру — я на этом уже ошибся один раз:

| страница | маркер | Worker |
| --- | --- | --- |
| `/` и `/catalog.html` | `data-lt-catalog-critical` | site |
| `/object.html` | `data-lt-object-critical` | backend |

Проверено обходом двенадцати публичных страниц поиском самого тела `price()`: больше нигде его нет — ни на `/agents.html`, ни на `/mortgage.html`, `/newbuildings.html`, `/newbuilding.html`, `/requests.html`, `/district-map.html`, `/calculator.html`, `/partners.html`, `/owners.html`.

Отсюда: править надо оба Worker. Одной правки site мало — на странице объекта цена останется без разрядов. В репозитории этот текст встречается только в `workers/site.mjs` и `workers/backend.mjs`, то есть в замороженных шаблонах — из `assets/` правка туда не дойдёт.

## Правка

Заменить тело `price()` целиком. Было, 211 символов:

```js
function price(value) {
    return text(value).replace(/(^|\s)(сом|USD|KGS)(?:\s+\2)+(?=\s|$)/gi, "$1$2").replace(/\$(\d{4,9})(?![\d.,])/g, (_, digits) => `$${digits.replace(/\B(?=(\d{3})+(?!\d))/g, " ")}`);
  }
```

Стало, 398 символов (+187):

```js
function price(value) {
    return text(value).replace(/(^|\s)(сом|USD|KGS)(?:\s+\2)+(?=\s|$)/gi, "$1$2").replace(/\$(\d{4,9})(?![\d.,])/g, (_, digits) => `$${digits.replace(/\B(?=(\d{3})+(?!\d))/g, " ")}`).replace(/(\d+)(\s*)(сом|KGS)(?![\wА-Яа-яЁё])/gi, (_, digits, gap, unit) => (digits.length > 3 && digits.length < 10 ? digits.replace(/\B(?=(\d{3})+(?!\d))/g, " ") : digits) + gap + unit);
  }
```

Добавленное правило группирует разряды в суммах, за которыми идёт «сом» или «KGS». Отрицательный просмотр не даёт зацепить слова вроде «сомнительно». Лукбехайнда нет намеренно: его не понимает Safari до 16.4.

## Сколько копий

На захвате от 18 ноября (site 5cfe5901, backend acf3371d) старое тело встречается в экранированном виде: в `workers/site.mjs` — 3 раза, в `workers/backend.mjs` — 5 раз. По одной копии в каждом бандле — это значение ключа `/listing-format.js` в карте ресурсов; она уже исправлена в `assets/`, и сборка подставит её сама. Остальные копии — инлайновые блоки, их и надо менять в тексте Worker.

Перед правкой пересчитайте: число копий меняется с каждой выкладкой.

## Проверка

`node platform/patches/2026-11-18-price-grouping.check.cjs` печатает обе версии, считает копии в шаблонах и прогоняет поведение новой `price()` на восьми случаях, включая «1500.50 сом», «45000 сомнительно» и повторное применение.

После выкладки проверять на живой странице, а не по файлу:

```js
window.LiberterraListingFormat.price('150000 сом')   // ждём «150 000 сом»
```

И глазами: карточка в каталоге должна показывать «150 000 сом / мес».
