# site-fixes

Патчи для **боевого сайта liberterra.kg**, а не для демо `index.html` в корне репозитория.
Исходники боевого сайта лежат отдельно (локальная папка `libertera-kg-accelerator`), поэтому фикс
лежит здесь как готовый файл + диф: заменить одноимённый файл в источнике и задеплоить обычным способом.

## telegram-membership.js

Гейт входа из Telegram. Что исправлено:

1. **Тупик в обычном браузере.** Ссылка с `tgWebAppPlatform=` (её легко скопировать или переслать из
   Mini App) полностью закрывала сайт сообщением «Не удалось подтвердить Telegram-сессию» без выхода.
   Теперь при ответе `401 invalid_session` показывается кнопка «Открыть сайт без Telegram»: она снимает
   гейт, чистит метки в `sessionStorage` и убирает `tgWebApp*`-параметры из URL.
2. **Залипание гейта.** Метка `liberterra-miniapp-entry-v1` ставилась от одного только параметра в URL,
   после чего в той же вкладке блокировался даже чистый `liberterra.kg`. Теперь метка ставится только
   при реальной сессии (`initData` / `tgWebAppData` / сохранённая сессия).

Правило подписки на группу не ослаблено: при подтверждённой сервером сессии и `subscribed:false`
гейт держится как раньше, кнопки выхода нет (как и при ошибке 503).

Проверено в браузере (Chromium, Pixel 7) на локальном стенде со стабом `/api/telegram-membership`:
вход с параметром без сессии, выход по кнопке, переход на чистый URL в той же вкладке, подтверждённая
сессия без подписки, с подпиской, и ответ 503.

## Что уже выложено на бой

17.11.2026 фикс выложен в воркер `liberterra-listing-ui` (Cloudflare, аккаунт
Mirbekbekov@gmail.com) тем же способом, каким сделаны остальные оверлеи, — дописан в конец модуля:

```js
files["/telegram-membership.js"] = "...";
```

Воркер отдаёт файлы из своей карты, а всё остальное проксирует в `hidden-pine-cbff` (binding
`BACKEND`), где файл лежит в статике (`ASSETS`). Поэтому запись в карту перекрывает бэкендную копию
для liberterra.kg; на `hidden-pine-cbff.mirbekbekov.workers.dev` остаётся старая версия.

**Важно:** это выкладка поверх. Следующий полный деплой из `libertera-kg-accelerator` затрёт её,
если тот же файл не положить в исходник. Откат — через версии воркера (версия до фикса:
`02cd8d0a-6b83-4f93-88ea-a8de01ca5f91` от 16:22 UTC).

## Не починено: /market-valuation.js

Файл отдаёт 404 и на liberterra.kg, и на воркере, хотя `object.html` его подключает. Без него
`marketValuationHtml()` в `object.js` видит пустой `window.LiberterraMarketValuation` и возвращает
пустую строку — блок оценки рынка молча пропадает со всех карточек объектов. Содержимого файла нет
ни в одном бандле и ни в одной доступной версии воркера, восстановить его можно только из исходника.
