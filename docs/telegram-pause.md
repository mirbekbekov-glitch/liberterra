# Пауза уведомлений Telegram

Бот @Liberterra_kg_bot не ведёт диалогов: он шлёт уведомления (регистрация,
модерация объявления, сертификат агента) и используется для входа и мини-приложения.

## Как поставить на паузу

Переменная Worker `hidden-pine-cbff`:

    TELEGRAM_NOTIFICATIONS = off      # уведомления не отправляются
    TELEGRAM_NOTIFICATIONS = (убрать) # уведомления снова идут

Значение сравнивается без учёта регистра и пробелов, выключает только `off`.

## Что затронуто

Под выключателем девять мест отправки: семь `sendMessage`, одно `sendPhoto`,
одно отправление медиа. Вместо запроса в Telegram код получает ответ
`{"ok":true,"muted":true}` — вызывающая сторона считает отправку успешной и
не падает.

Не затронуты: `getChatMember` (проверка подписки) и `getFile` (скачивание
присланных фотографий) — вход и мини-приложение продолжают работать.

## Чего это не выключает

Apps Script шлёт свои уведомления напрямую: `Code.gs` (пять мест),
`listing-moderation-notifications.gs` и `certificate-review.gs`. Их этот
выключатель не касается — нужен отдельный, через доступ к Apps Script.
