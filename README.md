# Liberterra — сайт, версия 2 (24.10.2026)

Один файл `index.html`: откройте двойным щелчком, сервер не нужен.
Интернет нужен только для шрифтов (Unbounded, Onest). Без интернета сайт работает на системных шрифтах.

## Что внутри

Для клиентов:
- Главная: поиск Снять/Купить, свежие проверенные объекты, заявки клиентов, схема «Как мы проверяем».
- Каталог: фильтры (сделка, тип, район, комнаты, цена, площадь, «только проверенные»), сортировка, вид списком, плитками и на условной схеме Бишкека.
- Страница объекта: две даты («Опубликовано» и «Актуально на»), агент с кнопками звонка и Telegram, запись на осмотр, вопрос агенту с готовыми фразами.
- Заявки (спрос ищет предложение), агенты с рейтингом и сертификатом, калькулятор ипотеки, избранное, переключатель сом / $.

Для агентов (переключатель «Клиент / Агент» вверху):
- Комиссия видна на карточках и на странице объекта: «Комиссия агенту 50%», ориентир доли, оговорка «итог после сделки».
- Кабинет: статистика объектов, «Что сделать сегодня», мои объекты с кнопкой «Подтвердить актуальность», общий каталог, заявки, профиль со статусом.
- Добавление объекта: направление Аренда/Продажа, обязательная отметка «договор подписан», объект уходит «На проверку».
- Путь агента: заявка → интервью → договор → одобрен.

## Что демо, а что нет

- Все объекты, агенты, цифры и номера вымышлены. Формы ничего не отправляют.
- Роль «Агент» переключается кнопкой только для показа. В рабочей версии роль определяется входом через Telegram и статусом «одобрен».
- Вместо фото генерируются иллюстрации.
- Схема района условная, не карта.

## Как подключить реальные данные

В начале скрипта есть блок `CONFIG`:
- `csvUrl` — ссылка на опубликованный CSV из Google Sheets. Колонки: `id, deal (rent|sale), type (apartment|house|commercial), title, district, street, rooms, area, floor, floors, usd, verified (1|0), agent, pub, act, desc`. Пока поле пустое, показываются демо-данные.
- `companyPhone`, `companyWhatsapp`, `companyTelegram` — номера Liberterra.
- `rate` — курс сом за 1 $.
- `commissionAgentPct` — доля закрывающего агента.
- `today` — для демо зафиксирована дата, в рабочей версии замените на `new Date()`.

Работает и как Telegram Mini App: при открытии внутри Telegram вызывается `WebApp.ready()` и `expand()`.
