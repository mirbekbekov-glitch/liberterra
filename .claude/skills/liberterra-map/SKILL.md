# Liberterra — карта Бишкека

Сейчас в `index.html` «карта» — условная схема по `DISTRICTS` (проценты x/y). Задача — заменить её на настоящую карту.

## Выбор провайдера (решить с владельцем, проверить актуальные условия и ключи)
- **Leaflet + OpenStreetMap** — бесплатно, без ключа, легко встроить в один файл. Политика OSM ограничивает тяжёлую нагрузку на их тайлы; для продакшена нужен свой тайл-провайдер.
- **2GIS MapGL** — хорошее покрытие Бишкека и привычен местным; нужен API-ключ и проверка лицензии.
- Google/Yandex — возможны, но с ключами и биллингом.
Не фиксировать выбор самостоятельно: спросить, если он не указан.

## Данные
- В объекте хранить `lat`, `lng` (WGS84) и `address`. Район (`district`) — для фильтра, не для позиции.
- В Postgres использовать PostGIS (`geography(Point,4326)` + GIST-индекс) для запросов «в пределах карты».
- Геокодирование адреса при добавлении объекта: подсказка адреса + ручная корректировка маркера перетаскиванием. Сохранять результат, не геокодировать при каждом показе.
- Для Бишкека центр по умолчанию примерно 42.8746, 74.5698, zoom 12.

## Поведение
- Запрашивать объекты по bounding box текущего экрана, с дебаунсом.
- Кластеры при большом числе маркеров; на маркере цена (`$` или `к сом` по `S.cur`).
- Клик по маркеру — мини-карточка с кнопкой «Открыть»; синхронизировать со списком.
- Адрес точной точки для неподтверждённых объектов не раскрывать (показывать район), если так решит владелец.
- Состояние карты (центр, zoom, фильтры) хранить в URL-хеше, чтобы ссылкой можно было поделиться.

## Совместимость
Сохранять правила проекта: `esc()` для всех строк в попапах, мобильная версия, режим карты как вариант вида (`S.f.view==='map'`).
